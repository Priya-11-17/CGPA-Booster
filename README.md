# 🎓 CGPA Booster – Academic Performance Tracker

A responsive, interactive web application designed to help students calculate their **SGPA, track their CGPA, analyze academic performance, and predict the grades required to achieve their target CGPA**.

Built using **HTML5, CSS3, JavaScript, and Chart.js**, this project provides a simple and effective way for students to monitor their academic progress.

## 🚀 Features

### 📚 1. SGPA Calculator
- Calculate SGPA based on subject credits and grade points.
- Dynamically add or remove subjects.
- Automatically calculate credit-weighted semester performance.

### 📊 2. CGPA Calculator
- Calculate cumulative GPA across multiple semesters.
- Track completed semesters and total academic credits.
- Automatically update CGPA when new semester results are added.

### 🎯 3. Target CGPA Predictor
- Set a desired CGPA.
- Enter the number of remaining academic credits.
- Calculate the average grade points required to reach the target.
- Identify whether the desired CGPA is mathematically achievable.

### 📈 4. Academic Performance Dashboard
- Visualize semester-wise SGPA using interactive line charts.
- Monitor academic progress.
- View previously saved semester results.

### 💾 5. Local Storage
- Automatically save semester records using JavaScript LocalStorage.
- Retain academic data after refreshing the browser.
- Delete individual semester records or clear all saved data.

### 📱 6. Responsive User Interface
- Clean and modern dashboard.
- Mobile-friendly design.
- Easy navigation and interactive buttons.
